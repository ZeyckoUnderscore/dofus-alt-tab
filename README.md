## Setup

### Prerequisistes

- Python 3.11.9 or higher
- Pipx 1.6.0 or higher ``pip install pipx``
- Poetry 2.1.2 or higher ``pipx install poetry``

### Installation

- Open terminal in project root
- Build package with poetry
``poetry build``
- Go to <project_path>/dist
- Install package
``pipx install dofus_alt_tab-X.X.X-py3-none-any.whl``

## Usage

Default keys:

- F2: previous window
- F3: next window
- F4: update windows

Activate script: ``dofus-alt-tab``

Stop script: ``ctrl+c``
